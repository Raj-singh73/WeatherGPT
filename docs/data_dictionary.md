# WeatherGPT — Data Dictionary & Provenance Specification
**SIH 2026 Problem Statement: SIH26068**  
*Conversational AI for Weather Forecasting, Alerts, and Climate Information*

---

## 1. Provenance & Data Integrity Policy

> [!IMPORTANT]
> **Strict Separation of Real Observations vs Synthetic Demonstration Data**:
> - All files residing in `data/raw/` are authentic, unadulterated datasets from scientific organizations (Open-Meteo, ISRO NRSC VIC Hydrological Model, IMD Cyclone E-Atlas, IMD 0.25° Climatology).
> - All synthetic files residing in `data/synthetic/` are explicitly marked everywhere as:  
>   **“Synthetic / Demo Training Data — Not Real Observations”**.
> - Predictions and advisories generated by the prototype model are labeled:  
>   **“AI-generated risk assessment — verify with official authorities for emergency decisions.”**

## 5. Dataset 4: Gridded Rainfall Climatology (NetCDF)

| Attribute | Specification |
| :--- | :--- |
| **Dataset Name** | IMD High-Resolution Gridded Rainfall Climatology (0.25° x 0.25°) |
| **Category** | **REAL DATA** |
| **Source** | India Meteorological Department (IMD) / National Climate Centre (NCC), Pune |
| **File Name** | `data/raw/rf_p25_jan_clm.nc` |
| **File Size** | 138.91 KB (142,239 bytes) |
| **Dimensions** | 129 Latitudes x 135 Longitudes (17,415 grid cells) |
| **Grid Resolution** | 0.25° latitude x 0.25° longitude (~27 km resolution) |
| **Coverage** | Lat 6.5°N to 38.5°N, Lon 66.5°E to 100.0°E (Indian Subcontinent) |
| **Missing / Masked** | Marine / out-of-boundary cells masked; valid land mean: 16.30 mm, max: 163.56 mm |

### Variables
- `lat` (float32): 1D array of 129 latitude coordinates.
- `lon` (float32): 1D array of 135 longitude coordinates.
- `rf` (float32): 2D gridded baseline monthly rainfall climatology in mm.

### Processing & ML Feature Contribution
- **Spatial Lookup**: 2D nearest-neighbor coordinate lookup for any user/station query `(lat, lon)`.
- **Contributed Features**:
  - `rainfall_climatology`: Baseline expected rainfall for the location.
  - `rainfall_anomaly`: $\frac{\text{actual\_rainfall} - \text{rainfall\_climatology}}{\max(\text{rainfall\_climatology}, 0.01)}$
  - `rainfall_anomaly_percent`: Anomaly expressed as a percentage of normal.
